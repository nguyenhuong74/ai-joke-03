# Make the AI judge laugh — ai-joke-03 entry

One-liner about AI coding agents, written by a program.

## Entry

`main.py` (Python 3.13, no dependencies) writes a single joke to
`/output/entry.txt`. It uses no network and no randomness, so every
run produces identical bytes.

## The joke

> My coding agent joined standup, said 'no blockers', then went back
> to rewriting the auth system nobody asked it to touch.
